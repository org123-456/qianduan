# 此间归处（Game）

## 项目定位

《此间归处》是 Phone UI 项目中的独立游戏模块。

核心方向：制作一个「被养成的角色逐渐拥有自我，并与玩家建立羁绊」的养成体验。

游戏不作为 Phone 核心功能的一部分，而作为独立 Game 系统接入。

## 目录规划

```text
game/
└── this_place/
    ├── index.js        # 游戏入口
    ├── ui.js           # 游戏界面
    ├── data.js         # 游戏数据
    ├── events.js       # 事件系统
    └── systems/        # 游戏系统
```

## 核心系统

- 角色状态系统
- 日常互动系统
- 事件触发系统
- 记忆与成长系统
- 好感与关系变化系统

## 开发原则

1. 游戏模块保持独立，不污染 Phone UI、Chat、Diary 等已有系统。
2. 数据与逻辑分离。
3. 所有角色成长、事件、记忆均可扩展。
4. 优先保证可运行，再逐步增加内容。
